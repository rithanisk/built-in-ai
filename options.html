Getting Started

1. The extension uses Google's built-in AI (no setup required)

2. Select text on any webpage and use the extension

3. The AI model will download automatically on first use

Features

  • Summarize: Get concise summaries of selected text
  • Translate: Translate text between multiple languages
  • Proofread: Check grammar and spelling errors
  • Q&A: Ask questions about selected text or images

Privacy

All text processing happens locally in your browser using Google's built-in AI. No data is sent to external servers. We don't store or log any of your data.
